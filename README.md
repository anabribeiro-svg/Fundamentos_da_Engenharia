# Fundamentos_da_Engenharia
Nesta matéria, estudamos conteúdos fundamentais para a formação em Engenharia, incluindo conceitos básicos de Ciência, Química e Expressão Gráfica, além de revisões dos principais conceitos de Física. Esses conhecimentos contribuíram para desenvolver uma base teórica importante para compreender e aplicar os princípios da Engenharia.
